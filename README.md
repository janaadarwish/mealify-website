
# 🍽️ Mealify Website

A responsive restaurant landing page built with HTML and CSS, showcasing a modern design for a food and restaurant website.

## 📌 Overview

Mealify is a front-end web development project designed to present a restaurant through an attractive interface, organized sections, and a user-friendly layout.

## ✨ Features

- **Modern UI:** Clean and visually appealing restaurant design.
- **Responsive Layout:** Designed to adapt to different screen sizes.
- **Restaurant Landing Page:** A dedicated homepage to introduce the restaurant.
- **Food-Focused Design:** Visual presentation of meals and restaurant content.
- **Navigation:** Structured sections for easy browsing.
- **Reusable Styling:** CSS-based layouts, typography, and visual effects.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/janaadarwish/mealify-website.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd mealify-website
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No additional installation is required.
